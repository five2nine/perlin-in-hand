# 🏔️ 펄린 노이즈 vs 심플렉스 노이즈 연산 복잡도 비교 (Perlin vs Simplex Noise Complexity)

본 문서는 절차적 콘텐츠 생성(Procedural Content Generation)에서 가장 널리 사용되는 두 가지 노이즈 알고리즘인 **펄린 노이즈(Perlin Noise)**와 **심플렉스/오픈심플렉스 노이즈(Simplex/OpenSimplex Noise)**의 수학적 연산 흐름, 차원별 시간 복잡도, 그리고 GPU(GLSL) 환경에서의 렌더링 성능 차이를 상세하게 분석합니다.

---

## 1. 차원별 연산 꼭짓점 및 보간 복잡도 비교

노이즈 알고리즘의 총 연산 속도는 **"평가해야 하는 꼭짓점(Vertex)의 개수"**와 **"격자를 찾는 수학적 복잡도"**의 상호작용으로 결정됩니다.

| 차원 ($N$) | 알고리즘 | 격자 꼭짓점 개수 ($2^N$ vs $N+1$) | 축 방향 선형 보간 횟수 | 격자 판별용 수학 연산 (Skewing / Sorting) | 종합 연산 속도 우위 |
| :--- | :--- | :---: | :---: | :--- | :---: |
| **2차원 (2D)** | **펄린 (Perlin)** | **4개** | 3회 | 없음 (`floor`만으로 판별) | **펄린 우세** (매우 가벼움) |
| | **심플렉스 (Simplex)** | 3개 | 없음 (방사형 감쇠) | 좌표 비틀기(Skewing) 및 대소 비교 1회 | |
| **3차원 (3D)** | **펄린 (Perlin)** | 8개 | 7회 | 없음 (`floor`만으로 판별) | **펄린 근소 우세** |
| | **심플렉스 (Simplex)** | **4개** | 없음 (방사형 감쇠) | 좌표 비틀기 및 성분 정렬 ($3! = 6$개 경로) | |
| **4차원 (4D)** | **펄린 (Perlin)** | 16개 | 15회 | 없음 (`floor`만으로 판별) | **심플렉스 우세** (역전) |
| | **심플렉스 (Simplex)** | **5개** | 없음 (방사형 감쇠) | 좌표 비틀기 및 성분 정렬 ($4! = 24$개 경로) | |
| **$N$차원** | **펄린 (Perlin)** | **$2^N$개** (기하급수 증가) | $2^N - 1$회 | 없음 | **심플렉스 압도** |
| | **심플렉스 (Simplex)** | **$N+1$개** (선형 증가) | 없음 | 성분 정렬 ($N!$개 경로) | |

## 2. 알고리즘별 연산 항목 및 흐름 세부 분석

### 2.1. 펄린 노이즈 (Perlin Noise - 2002년 개선형)

정사각형/정육면체 격자를 가로지르며 축 방향으로 보간을 누적해 나가는 방식입니다.

#### 1) 연산 순서 및 항목
1. **정수 격자점 판별**: 입력 좌표 $P(x, y, z)$에 대해 단순 내림(`floor`) 연산으로 소속 격자 셀의 좌하단 꼭짓점 좌표를 확보합니다.
2. **상대 거리 벡터 계산**: 꼭짓점 8개 각각에서 타겟 점 $P$를 가리키는 8개의 변위 벡터 $D_i$를 연산합니다.
3. **그라디언트(기울기) 해싱**: 각 꼭짓점 좌표의 정수 성분을 의사 난수 함수(Hash/Permutation Table)에 통과시켜 미리 정의된 12개(또는 16개)의 무작위 방향 벡터 중 하나인 기울기 벡터 $G_i$를 선택합니다.
4. **내적 연산**: 8개 꼭짓점 각각에 대해 $G_i \cdot D_i$ 내적(Dot Product)을 수행합니다. (결과값: $n_{000}, n_{100}, \dots, n_{111}$)
5. **감쇠 함수 곡선 적용**: 격자 내부 상대 좌표 $u, v, w$에 대해 2차 도함수가 연속되도록 Ken Perlin의 5차 다항식 감쇠 함수를 계산합니다.
   $$S(t) = 6t^5 - 15t^4 + 10t^3$$
6. **다중 선형 보간 (Lerp)**: 감쇠 계수 $S(u), S(v), S(w)$를 가중치로 삼아, X축 방향 4회 $\to$ Y축 방향 2회 $\to$ Z축 방향 1회 순으로 선형 보간을 누적 적용합니다.

#### 2) 시간 복잡도
* **시간 복잡도**: **$O(2^N)$** (차원이 늘어날수록 보간 연산과 해시 테이블 참조량이 $2^N$으로 폭증)

### 2.2. 심플렉스 노이즈 (Simplex Noise)

공간을 정삼각형/정사면체 단위인 **심플렉스(Simplex)**로 비튼 후, 꼭짓점 중심의 구형(Radial) 영향력 가중치로 합산하는 방식입니다.

#### 1) 연산 순서 및 항목
1. **공간 시어링 변환 (Skewing)**: 입력 좌표 $P(x, y, z)$를 정삼각형/정사면체 격자계로 정렬하기 위해 아래 상수를 곱해 좌표계를 비틉니다.
   $$F_N = \frac{\sqrt{N+1}-1}{N} \quad \left(F_2 \approx 0.366, \quad F_3 = \frac{1}{3}\right)$$
2. **단위 심플렉스 셀 판별**: 찌그러진 격자 공간 상에서 내림(`floor`) 연산 후 소수점 이하의 분수 성분($dx, dy, dz$)을 계산합니다.
3. **진입 심플렉스 경로 탐색 및 꼭짓점 추출 (Sorting)**: 
   * $dx, dy, dz$의 상대적인 크기를 비교하여 정렬합니다. 
   * 예를 들어 $dx > dy > dz$라면, 점 $P$가 속한 사면체의 꼭짓점 경로는 $(0,0,0) \to (1,0,0) \to (1,1,0) \to (1,1,1)$ 순서가 됩니다. 
   * 이 정렬 연산은 차원 $N$에 대해 **$N!$** 개의 분기 경로를 가집니다.
4. **공간 역시어링 변환 (Unskewing)**: 찾아낸 $N+1$개의 꼭짓점 좌표를 다시 원래 공간 좌표계로 돌려놓기 위해 역변환 상수를 곱합니다.
   $$G_N = \frac{1 - \frac{1}{\sqrt{N+1}}}{N} \quad \left(G_2 \approx 0.211, \quad G_3 = \frac{1}{6}\right)$$
5. **그라디언트 해싱 및 내적**: 원래 좌표계 기준 꼭짓점 $N+1$개에 대해 난수 벡터 $G_i$를 구하고, 꼭짓점과 점 $P$ 사이의 실제 거리 벡터 $D_i$와 내적($G_i \cdot D_i$)을 계산합니다.
6. **방사형 가중치 감쇠 및 최종 합산**: 각 꼭짓점 중심의 방사형(Circular/Spherical) 영향력 가중치 곡선을 연산하여 내적 값들과 곱한 뒤 최종 누적합니다. (선형 보간 루프가 존재하지 않음)
   $$\text{Noise}(P) = \sum_{i=1}^{N+1} \max\left(0, \ r^2 - |D_i|^2\right)^4 \cdot \left(G_i \cdot D_i\right)$$
   *(2D의 경우 $r^2 = 0.5$, 3D의 경우 $r^2 = 0.6$)*

#### 2) 시간 복잡도
* **시간 복잡도**: **$O(N^2)$** 또는 소수부 정렬 알고리즘 효율에 따라 **$O(N \log N)$** (고차원으로 갈수록 펄린 노이즈의 $O(2^N)$보다 월등히 빠름)

### 2.3. 오픈심플렉스 노이즈 (OpenSimplex - 2014)

켄 펄린의 특허를 회피하고 축 방향 왜곡을 최소화하기 위해 **BCC(Body-Centered Cubic, 체심 입방) 격자**를 기본 격자로 채택한 설계입니다.
* 3차원 공간에서 일반 심플렉스는 4개의 꼭짓점 가중치를 구하지만, OpenSimplex(2014)는 BCC 격자의 투영 특성상 점의 정수/소수부 오프셋 위치에 따라 **8개 또는 24개의 꼭짓점**을 평가하게 됩니다.
* 일반 심플렉스보다 조금 더 부드럽고 격자 줄무늬 왜곡이 전혀 없는 장점이 있지만, **2D/3D 환경에서의 절대적인 사칙연산 연산량 및 해싱 비용은 일반 심플렉스나 펄린에 비해 더욱 무겁습니다.**

## 3. GPU (GLSL) 셰이더 내에서의 설계 및 최적화 쟁점

GPU 상에서 노이즈 알고리즘을 GLSL로 구현하여 실행할 때, 다음과 같은 아키텍처적 유불리가 작용합니다.

### 3.1. 분기 회피 (Branchless Programming)
* **GPU의 하드웨어 특성**: 동일 워프(Warp, 32개 스레드 집합) 내의 스레드들이 조건문 분기(`if-else`)에 의해 서로 다른 실행 경로로 갈라지면, GPU 하드웨어는 경로들을 순차적으로 실행(Warp Divergence)하여 처리 성능이 반감됩니다.
* **해결책**: 현대 GLSL 기반 심플렉스 구현체는 내장 함수인 `step()`, `clamp()`, `max()` 등을 활용하여 사면체 검색 단계에서 `if` 문을 단 한 개도 쓰지 않는 **Branchless 수학식**으로 우회하여 GPU 병렬 성능을 온전히 유지합니다.

### 3.2. 의사 난수 해싱 (On-the-fly Math Hash vs Texture Lookup)
* **텍스처 룩업 방식 (과거)**: 셰이더 내에서 매번 해시를 연산하는 비용을 아끼기 위해 256 크기의 난수 순열 테이블(Permutation Table)을 1D/2D 텍스처(Texture)로 만들어 GPU 메모리에 올려두고 탐색(Sampling)했습니다.
  * *문제점*: 4차원 펄린의 경우 16번의 꼭짓점을 찾을 때 수십 번의 연쇄 텍스처 룩업이 일어나 **메모리 대역폭 및 지연 시간(Memory Latency)** 병목이 발생했습니다.
* **수학식 연산 방식 (현대)**: GPU 연산 유닛의 클럭당 처리 속도가 급격히 향상됨에 따라, 메모리에서 텍스처를 긁어오는 것보다 셰이더 내부에서 수학적 나머지 연산이나 곱셈을 조합한 **해시 함수(예: Gustavson의 `mod289` 연산)**를 실시간 계산하는 것이 3배 이상 빠릅니다.

### 3.3. 최종 렌더링 성능 임계점 (Turning Point)
* **3차원 이하 (정적 지형)**: 꼭짓점 처리 개수 차이(펄린 8개 vs 오픈심플렉스 8~24개)와 격자 탐색 연산 강도를 계산해 보면, 펄린 노이즈가 명령어 수(Instruction Count)가 현저히 적어 더 높은 프레임률(FPS)을 방어합니다.
* **4차원 (시간 애니메이션 지형)**: 출렁이는 3D 지형 효과를 주기 위해 4D 노이즈를 사용할 경우, 펄린은 16개 꼭짓점에 대해 복잡한 4차원 그라디언트 해싱 연산이 필요해 셰이더가 비대해집니다. 반면 심플렉스는 5개의 꼭짓점 가중치만 연산하므로 **4D 연산에서는 GPU에서도 심플렉스 계열이 압도적으로 가볍고 원활하게 구동**됩니다.
